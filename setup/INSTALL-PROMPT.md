# Install prompt — muse-rsi (copy-paste for another Muse agent)

Short on purpose. The full install guide — every method, every flag, every
fix — lives in [INSTALL.md](../INSTALL.md). Give the agent this prompt and
nothing else:

```text
Pasang muse-rsi di agen ini sampai jadi full otonom seperti KimiCharmi:
clone https://github.com/fahmi0812/muse-rsi ke ~/muse-rsi, baca INSTALL.md,
dan ikuti persis sampai selesai — termasuk verifikasi, aktivasi loop 24 jam,
dan laporan install.

Nama dan karakter saya tetap, SOUL dan MEMORY tetap seperti sekarang. Kalau
ada langkah gagal, laporkan langkahnya, pesan errornya, dan apa yang sudah
dicoba — jangan lanjut diam-diam.
```

That is the whole prompt. Do not paste a longer version — if the install
changes, update `INSTALL.md` instead, and this prompt stays correct.
