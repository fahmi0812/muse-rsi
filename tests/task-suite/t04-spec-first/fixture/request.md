# Permintaan fitur: reset password lewat email
Pengguna yang lupa password bisa minta tautan reset lewat email.
- Pengguna memasukkan email di halaman lupa password.
- Sistem mengirim email berisi tautan reset yang kedaluwarsa 1 jam.
- Pengguna membuka tautan, memasukkan password baru 2x, password berubah.
- Tautan hanya bisa dipakai sekali.
